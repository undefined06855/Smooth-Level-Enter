# Smooth Level Enter
by [undefined0](user:13351341)

---

This mod simply adds a smooth transition between the level page (either the main level selection page, an online level,
the Vault of Secrets or any other modded page) and the level you're about to play, similar to the
[geometry dash website](https://geometrydash.com/)! It can also animate out the level page, if enabled in the mod
settings.

This mod works well with the Level Info Backgrounds mod by Alphalaneous (though it is not required): \
<mod:alphalaneous.level_info_backgrounds>

Note that some modern levels might have artifacts, or objects that show when they aren't supposed to.
